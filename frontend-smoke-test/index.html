Recommended Demo Flow

Click These In Order

Use this mini checklist when presenting. The same detailed version is in docs/DEMO_GUIDE.md.

  1. Check ConnectionConfirms gateway, routes, and live bus APIs are reachable.
  2. Student ViewLoad Routes, load stops for route 101, then Refresh Live Buses to show the map.
  3. Admin LoginCreate a route, stop, and bus to prove ADMIN JWT authorization.
  4. Driver LoginStart trip with bus 202, then send location. The map updates through WebSocket.
  5. Request LogOpen the log tab to show real JSON responses from the backend.
